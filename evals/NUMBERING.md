# Scenario Numbering

The headline suite keeps historical scenario numbers so hosted run comparisons and PR discussion
links stay understandable. Gaps are intentional when scenarios move to `evals-reference/` or are
retired from the headline set.

`50-reference-command-sanitizer-feature` to `50-command-sanitizer-feature` so the active path no
